請製作一個瀏覽器 3D 教學遊戲網站，使用 Three.js（r128，從 cdnjs 載入），輸出成單一 index.html，可直接部署到 GitHub Pages。學生會用平板或筆電開啟網址遊玩。

【對象與單元】
臺灣國小四年級自然科「月亮」單元的課後複習，對應 108 課綱。

【學習目標】（過關必須用到這些概念，不是另外出選擇題）
1. 月亮本身不發光，是反射太陽光
2. 月相依序變化：新月 → 眉形月 → 上弦月 → 盈凸月 → 滿月 → 虧凸月 → 下弦月 → 殘月 → 新月，週期約 29.5 天（約一個月）
3. 月相與農曆日期的對應：初一前後新月、初七八上弦月、十五六滿月、廿二三下弦月
4. 能從已知的月相或農曆日期，推算出接下來哪一天是新月（最暗的夜）

【學生常見迷思】（請設計關卡讓學生自己發現錯誤）
- 以為月相是地球的影子遮住月亮造成的（遊戲中絕對不可以用這種方式呈現）
- 以為上弦月和下弦月亮的是同一邊
- 以為滿月之後隔幾天就是新月

【遊戲故事】
玩家是一隻臺灣本土夜行動物「白鼻心」，想趁夜晚溜進果園偷吃水果。果園有拿手電筒的巡守員。月光越亮，巡守員看得越遠；最暗的新月夜晚最容易成功。

【遊戲流程】
每一關分成兩個階段：
1. 情報階段（2D 月曆）：畫面提供線索，例如「今天晚上是上弦月」或「今天是農曆初十」，學生要在月曆上選出最適合行動的夜晚。
2. 潛入階段（3D 果園）：月光亮度、陰影和巡守員的視線範圍，由選擇日子的月相決定。選對新月，夜色最暗、容易成功；選錯，月光較亮、巡守員視線變長，比較容易被發現。

被發現或選錯日子時，不要只顯示失敗，要用一兩句話說明原因，例如「你選的是農曆十五，正好是滿月，月光最亮！」，並讓學生重新推算。

【關卡設計】共 4 關，難度逐漸增加
- 第 1 關：排列月相。收集散落的月相卡片，依正確順序排好，才能取得月曆。
- 第 2 關：給月相圖片線索（例如上弦月），推算新月是哪一天。
- 第 3 關：只給農曆日期線索，推算新月是哪一天。
- 第 4 關：給下弦月或殘月這類容易混淆的線索，考驗學生分辨上弦月和下弦月。
全部過關後顯示總結畫面，複習八種月相和對應的農曆日期。

【科學呈現規則】（正確性優先於視覺效果）
- 月相名稱使用臺灣課綱用語：新月、眉形月、上弦月、盈凸月、滿月、虧凸月、下弦月、殘月（不用「娥眉月」「凸月」）
- 以臺灣（北半球）看到的方向呈現：漸盈時右側亮，漸虧時左側亮；上弦月右半亮，下弦月左半亮
- 月相圖使用 Canvas 繪製，亮部比例 illum = (1 - cos θ) / 2，明暗交界線是 x 半軸為 |cos θ| × r 的半橢圓
- 新月時夜空中看不到月亮，不可畫成黑色圓形掛在天上
- 3D 場景的月光強度要和月相亮部比例一致

【裝置與效能】
- 要能在學校的 iPad、Chromebook 和一般筆電上順暢執行：低多邊形模型、限制像素比（最多 2）、避免耗效能的特效
- 同時支援觸控（虛擬搖桿）和鍵盤（方向鍵或 WASD）
- 平板橫向、直向都能操作，按鈕夠大，方便國小學生點選
- 所有模型和材質用程式生成，不使用外部圖片 API，也不放任何 API 金鑰
- 不需要登入，不收集或儲存任何學生個人資料

【介面】
- 全部使用繁體中文，字體夠大，文字以國小四年級能讀懂為準
- 遊戲中隨時可以打開「月相小幫手」，查看八種月相的圖片和名稱（第 4 關除外）
- 每關都有簡單的操作說明

【程式撰寫規則】
- JavaScript 使用 var 和傳統 function，不使用箭頭函式和模板字串
- <script> 中不可出現特殊 Unicode 字元（數學減號、破折號、中點、勾號、智慧引號）
- 每次修改後，用 Node.js 檢查 JavaScript 語法

【工作方式】
- 不要問我設計問題，請自行判斷並完成
- 先做出可以玩的最小版本（第 2 關），再逐步加入其他關卡
- 頻繁 commit，並持續把設計決定和變更寫進 notes.md
- 用 Playwright 測試筆電（1366×768）和平板（1024×768 橫向、768×1024 直向）尺寸，確認畫面沒有破版且可以操作
